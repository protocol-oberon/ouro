Error [SYN0008]: Invalid Function Name
  ┌── │SYN0008-InvalidFunctionName.ouro:1:1│
  │
1 │ (define/procedure with () 1)
  │ ^
  │ Naming Rule: 'with' is read by its syntax, so a function cannot take its name.
  │ 

'with' is read by its syntax before any name is bound, so a function named after it could never be
called by it. Perhaps choose another name.
