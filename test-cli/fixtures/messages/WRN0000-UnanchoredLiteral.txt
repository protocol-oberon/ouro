Ouro evaluates floating values inside array and record layers as unanchored literals. Because this value is
positioned directly next to #record-empty, it has no semantic binding key and will be completely erased from
properties at compile time.

Perhaps assign it to a property attribute key (e.g., :label "x"), if it is intended to be saved.
