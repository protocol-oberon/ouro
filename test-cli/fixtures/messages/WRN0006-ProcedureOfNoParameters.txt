Warning [WRN0006]: The procedure 'museum' takes no parameters, so it is a constant
  ┌── │WRN0006-ProcedureOfNoParameters.ouro:1:1│
  │
1 │ (define/procedure museum ⊢ string () "Rijksmuseum")
  │ ^
  │ Constant: museum
  │ 

A function of no parameters is a constant: named as a value it is its result, worked out once per
document, whichever keyword defines it.

Perhaps define it as one: (define/constant museum value).
